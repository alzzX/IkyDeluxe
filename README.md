# Ikyy AM Premium Tools (Termux)

Developer: IkyyCode

## Install
```
pkg install unzip -y
unzip IkyyAMPrem.zip && cd IkyyAMPrem
bash install.sh
```

## Jalankan
```
python amprem.py
```

Atau lewat command langsung:
```
python amprem.py sendlink email@example.com
python amprem.py verify LINK_MAGIC
python amprem.py status
```
